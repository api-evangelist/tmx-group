# TMX Group

> TMX Group operates Canadian capital-markets infrastructure (Toronto Stock Exchange, TSX Venture Exchange, TSX Alpha, Montreal Exchange) and sells market data through TMX Datalinx. Its self-serve TMX Analytics platform exposes REST Data Science APIs (V1 POST-based on analyticsapi.tmxanalytics.com, V2 GET-based on insightapi.tmxanalytics.com) for Canadian and US equity daily stats, intraday trade/quote bars, TAQ NBBO tick data, broker analytics, short interest, buybacks, corporate actions and reference data, and Montreal Exchange options and futures analytics. Auth is a hub-issued x-api-key plus a one-hour bearer token from POST /v1/authn. No public OpenAPI is published; docs are generated HTML.

Generated by API Evangelist enrichment pipeline (method: generated) from apis.yml and repo artifacts, 2026-07-22.

## APIs

- [TMX Essential Analytics for Equities API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-essential-analytics-for-equities): End-of-day CA/US equity daily stats and liquidity analytics (POST /v1/ca/dailystats, /v1/us/advanceddailystats, ...)
- [TMX Equity Intraday Trades and Quotes API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-equity-intraday-trades): 1-min/1-sec trade and quote bars for CA/US equities
- [TMX Trades and Quotes Tick Data (TAQ NBBO) API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-trades-and-quotes-tick-data): Historical tick data with NBBO (/v1/ca/taqnbbo, /v1/us/taqnbbo)
- [TMX Broker Analytics API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-broker-analytics): Broker daily stats, liquidity, and summaries for Canadian markets
- [TMX Corporate Actions and Reference Data API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-corporate-actions-and-reference-data): Issuers, global symbols and deltas, corporate actions, TSX reference data, S&P/TSX indices
- [TMX Options and Futures Analytics API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-essential-analytics-for-options-and-futures): Montreal Exchange derivatives analytics (/v1/ca/mxdailystats)
- [TMX Short Interest Analytics API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-short-interest-analytics): Days to cover and percent of float for Canadian listings
- [TMX Buybacks API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-buybacks): North American share buyback activity (/v1/northamericanbuybacks)
- [TMX Price Adjustment Curve API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-price-adjustment-curve): Price adjustment curves (/v1/pac, /v1/pacexplain, /v1/original, /v1/smoothened)
- [TMX MOC Imbalance Analytics API](https://docs.tmxanalytics.com/#prod-tmx-ds-api-new-moc-imbalance-analytics): TSX closing-auction imbalance analytics (/v1/ca/moci)
- [TMX Data Science API V2 (Insight API)](https://docs.tmxanalytics.com/#tmx-data-science-api-v2): GET-based V2 on insightapi.tmxanalytics.com/v2 - broker analytics, reference data, CRV bulletins/entitlements/FITC/SMF, S&P/TSX index datasets
